# 📂 BIMIPAL PROJECT CARD (v5.1 "AI Autopilot & Smart Control")

**Мета:** Накопичити кошти на цілі (Відпустка, Курси, Консоль), використовуючи глибоку автоматизацію для усунення ліні при фіксації витрат та ШІ для фінансової дисципліни.

### 🛠 Технічний стек (Current State)
* **Мова:** Python 3.12+ (aiogram 3.x, асинхронність).
* **База даних:** Google Sheets API (gspread) + розумне кешування in-memory (60s).
* **Інтеграції:** Monobank Personal API (Webhooks) через `aiohttp` та Cloudflare Tunnel.
* **Штучний Інтелект:** OpenRouter API (openai lib). Моделі: `openrouter/free` (Аналітика), `google/gemma-4-26b-a4b-it:free` (Парсинг фото).
* **Аналітика:** Matplotlib, ReportLab.
* **Інфраструктура:** Docker на CasaOS (режим 24/7). CI/CD через `start.sh` та GitHub.
