# 📂 BIMIPAL PROJECT CARD (v6.1 "SQL-Only & Clean Architecture")

**Мета:** Розвиток масштабованої SaaS-платформи на базі Telegram Mini Apps та PostgreSQL. Бот виконує роль "Zero-Friction" інтерфейсу для швидкого введення даних та AI-обробки, а весь менеджмент бюджету відбувається у BimiApp.

### 🛠 Технічний стек (Current State)
* **Мова:** Python 3.12+ (aiogram 3.x, асинхронність).
* **База даних:** Повна відмова від Google Sheets. Усі дані зберігаються у PostgreSQL через REST API мікросервісу `BimiFinance`.
* **Інтеграції:** Monobank Personal API (Webhooks) через `aiohttp`.
* **Штучний Інтелект:** OpenRouter API (openai lib). Моделі: `openrouter/free` (Аналітика), `google/gemma-4-26b-a4b-it:free` (Парсинг фото).
* **Архітектура:** Thin Client (Тонкий клієнт). Telegram-бот лише обробляє вебхуки та введення, вся бізнес-логіка та обчислення перенесені на мікросервіс.

### 🗺 BIMIPAL PROJECT ROADMAP

**✅ Етап 1-3: Автопілот, Smart Receipts, Мікросервіси (Завершено)**
* Інтеграція Monobank, AI-Парсер чеків (Vision + NLP), AI Інсайти.
* Піднято BimiFinance (FastAPI + PostgreSQL + React).

**✅ Етап 4: The Great Migration & SaaS Onboarding (Завершено)**
* [x] **Zero-Friction Onboarding:** Реєстрація нових сімей через `/start` з безпечними інвайт-посиланнями (хешами).
* [x] **Telegram Mini App (BimiApp):** Інтерактивні графіки (Recharts), управління скарбничками, редагування транзакцій та налаштування токенів.
* [x] **Відмова від Google Sheets:** Автономний скрипт мігрував історію в Postgres. Бот переведений на SQL-Only режим.
* [x] **Smart Scratchpad (Чернетка):** Сімейна нотатка з автоматичним калькулятором (парсинг валют `грн`, `$`, `€`) та діленням рахунку на компанію.

**🚀 Етап 5: The Grand Refactoring (Поточний)**
* [ ] **Розпил Моноліту:** Поділ `main.py` на ізольовані роутери: `handlers/`, `services/`, `keyboards/` (Clean Architecture).
* [ ] **Фільтрація та Експорт:** Додавання панелі фільтрів у BimiApp та можливість експортувати історію сім'ї у CSV/Excel.
* [ ] **Оптимізація Балансів:** Винесення опитувань Monobank API у фонові задачі (Celery/APScheduler) на бекенді для миттєвого завантаження статистики.

**🔮 Етап 6: The Killer Features**
