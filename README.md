# BimiPal

**BimiPal** — це розумний Telegram-бот, який виконує роль персонального фінансового тренера та автоматизованого сімейного бухгалтера. Проєкт поєднує можливості Open Banking, Штучного Інтелекту та хмарних таблиць для досягнення максимального фінансового контролю з нульовими зусиллями (Zero Friction).

### 🔥 Ключові можливості (v5.1):

* **Автопілот (Monobank):** Бот миттєво перехоплює транзакції через Webhooks. Більше не потрібно вводити суми вручну — достатньо просто натиснути кнопку категорії в чаті.
* **Штучний Інтелект (AI Receipts):** Відправте фото фіскального чека, і ШІ автоматично розпізнає товари, їх кількість та вагу, перекладе касові абревіатури на нормальну мову і прив'яже їх до транзакції в банку.
* **Inbox Zero & AI Insights:** Щовечора о 21:30 бот перевіряє нерозібрані транзакції, допомагає швидко розкласти їх по поличках (конвеєрне сортування) та видає коротку аналітику дня згенеровану AI-тренером.
* **Розумна Статистика:** Автоматичне вираховування готівки на основі різниці між історією в Google Sheets та реальними залишками на рахунках Монобанку.
* **Сімейна синхронізація:** Роздільні баланси (Аня / Вадим), швидкі перекази між собою в 1 клік та єдиний облік спільного капіталу і сейфу в USD.
* **Потужна аналітика:** Автоматична генерація PDF-звітів за місяць та кругових діаграм витрат.

### 🛠 Технічний стек:

* **Мова:** Python 3.12+ (aiogram 3.x, aiohttp)
* **AI & OCR:** OpenRouter API (Vision + Text NLP моделі)
* **Backend:** Google Sheets API (gspread)
* **Аналітика:** Matplotlib, ReportLab
* **Інфраструктура:** Docker на CasaOS (режим 24/7), Cloudflare Tunnel.
